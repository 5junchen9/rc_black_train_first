# Black robotics training source archive

This repository is a sanitized, source-only backup of a Black robotics training project based on mjlab.

The source import is in progress. This initial commit is only the archive landing page, not a completed project backup.

Scope: project source code, reviewed configuration, tests, and historical source snapshots organized into archival branches. The branches are archival snapshots reconstructed from source directories, not a claim that they were pre-existing development branches.

Excluded: trained weights/checkpoints, trajectories, private runtime manifests, approval records, credentials, caches, virtual environments, and binary assets. Robot geometry with unverified redistribution rights is also excluded. These private or separately licensed inputs remain outside this public repository.

Source snapshots are preservation artifacts. They are not deployment releases or proof of training, numerical validation, or independent reproducibility. Live training files are not modified by this backup.

Existing upstream license and copyright notices will be retained with imported source.
